# Python Sandbox para run_python tool

El tool `run_python` ejecuta código con estas librerías pre-cargadas:
- `pd` (pandas)
- `np` (numpy)
- `plt` (matplotlib.pyplot, backend Agg)

## Instalación

```bash
cd scripts/python-sandbox
pip3 install -r requirements.txt
```

O con el Python del sistema:
```bash
python3 -m pip install pandas numpy matplotlib
```
